# 乐遇同频 · 校园演出搭子社区

> 看演出这件事，不该一个人去。—— 找到同校一起冲那场演唱会的人，认识全校和你听同一位歌手的人。

一个面向高校圈的校园演出社交 App 原型：演出雷达 + 搭子广场 + idol 应援墙，iPhone 尺寸移动端界面（底部 Tab 导航、发布面板、抖音式个人主页）。

## 功能

- **演出雷达**：浏览/发布校园周边演出情报，标记「想去」
- **搭子广场**：发布搭子招募（同校优先/拼车/拼住宿/散场约饭），举爪报名，一人一票
- **搜索找搭子**：首页右上角放大镜进入搜索页，按歌手 / 演出 / 学校 / 标签实时检索所有招募帖
- **idol 应援墙**：一键创建自己的偶像应援墙，加入后可发应援动态、点赞
- **我的**：抖音式个人主页——获赞/搭子/关注歌手/粉丝、作品九宫格
- **「我的」八大第二界面**：找搭子筛选（按同校/同演出/标签）、新访客、票务中心（原价捡漏）、我的票夹、演出日历（按月分组）、现场足迹、私密行程（🔒/👁 可切换）、全部功能入口
- **使用导引**：首次进入自动弹出 5 步图文导引，设置页可随时重看
- **手机模型**：桌面预览时渲染 iPhone 外壳（灵动岛 + 状态栏：实时时间 / 信号 / Wi-Fi / 电量），真机自动隐藏
- **消息中心**：系统通知 + 未读红点
- **账号系统**：手机号 + 验证码登录，Bearer Token 会话（7 天）

## 技术栈

- 前端：原生 HTML/CSS/JS 单页应用，零依赖，移动端优先
- 后端：Node.js 原生 `http` + `node:sqlite`（DatabaseSync），**零第三方依赖**
- 数据库：SQLite 文件（首次启动自动建表 + 播种示例数据）

## 本地运行

```bash
cd backend
node server.js        # 需 Node 22+（node:sqlite）
```

然后打开 http://localhost:3000 （或双击根目录 `start.bat`）。

> 开发模式下，验证码会直接显示在登录页提示和后端日志里（devCode），接入真实短信服务时替换 `sendCode` 相关段落即可。

## 在线体验（手机可直接打开）

**https://hkh168.github.io/samefreq/**

GitHub Pages 是纯静态托管，跑不了 Node 后端。所以线上版内置了一套**本地演示引擎**：
页面检测到 `/api/*` 不可用时会自动切换，用浏览器 `localStorage` 复刻全部接口 ——
**登录、发布演出、创建应援墙、加入墙、发应援动态、点赞、改昵称/头像/签名、消息中心全部可用**，
数据存在你自己的浏览器里（换设备或清缓存会重置）。

> 想要带真实数据库、多设备同步的版本，本地跑 `start.bat` 即可，前端会自动优先连后端。

## 目录结构

```
├── index.html        # 主站（单页应用）
├── login.html        # 登录页
├── 404.html          # 自定义 404（路径写错自动跳回首页）
├── start.bat         # Windows 一键启动
├── 产品说明.md        # 产品文档
└── backend/
    ├── server.js     # 全部后端逻辑（http + sqlite）
    └── tongpin.db    # SQLite 数据文件（运行时生成，不入库）
```
